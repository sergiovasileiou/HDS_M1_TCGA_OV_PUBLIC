| FIGO | International Federation of Gynecology and Obstetrics (staging system) |

| GDC | Genomic Data Commons, run by the NCI |
| GOG | Gynecologic Oncology Group (trial names such as GOG 218) |
| HGSC | High-grade serous carcinoma |
| ICD-10 | International Classification of Diseases, 10th revision |
| MRC | Medical Research Council |
| MSt | Master of Studies |
| NA | Not available: a missing value in R |
| NCI | National Cancer Institute (United States) |
| OR | Odds ratio |
| OS | Overall survival |
